# Dataset

This directory contains the anonymised keyword-frequency dataset used by
the Streamlit application and dissertation analysis.

## Data file

- `your_dataset.csv`: Keyword-frequency observations used in the analysis.

Replace the filename above with the actual dataset filename.

## Variables

Document the actual columns in the uploaded dataset. For example:

- `date`: Observation date or beginning of the observation week.
- `keyword`: Anonymised keyword identifier.
- `count`: Number of keyword occurrences during the observation period.

## Coverage

The dissertation analyses weekly keyword-frequency observations covering
the study period from February 2022 to February 2026.

## Processing

The source records were aggregated into weekly keyword counts. Any
filtering, treatment of missing weeks, anonymisation or other preprocessing
should be documented here.

## Conditions of use

The dataset is supplied for research reproducibility. Users should consult
the original data-provider conditions before connecting the anonymised
records with underlying news articles or source materials.
